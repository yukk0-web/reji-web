文化祭バザー POS（試作版）
================================

商品:
- 肉巻きおにぎり 350円
- チーズ肉巻きおにぎり 400円

機能:
- 注文・合計金額・連番発行
- 注文状態（調理中→提供可能→提供済み）
- 商品別販売数と売上集計
- CSV保存、JSONバックアップ・復元
- localStorageへの端末内保存
- Service Workerによるオフライン起動用キャッシュ

重要:
- このZIPを解凍して index.html を直接開くだけでは、Service Workerが登録されない場合があります。
- オフライン起動には、HTTPSで公開したサイトをオンライン中に一度開き、Service Workerの登録・キャッシュ完了後にホーム画面へ追加してください。
- GitHub PagesなどのHTTPS静的ホスティングが使えます。公開後は、スマホでサイトを開き、注文テスト→画面を閉じる→機内モードで再起動、のテストを必ず行ってください。
- 注文データはブラウザのlocalStorageに保存されます。ブラウザのデータ消去、プライベートブラウズ、端末故障などで失われる可能性があります。営業前・途中・終了後にCSV/JSONバックアップを推奨します。
- iPhoneではSafariでサイトを開き「共有」→「ホーム画面に追加」を使用してください。AndroidではChromeのメニューから「ホーム画面に追加」または「アプリをインストール」を選んでください（表示名は機種によって異なります）。
- この試作版はスマホ1台用です。端末間同期はありません。
- 実際の販売前に、テスト注文・取消・再起動・オフライン・バックアップ復元を必ず確認してください。


番号札の再利用:
- 初期設定は番号札001〜020の20枚です。
- 注文を確定すると、未使用の最小番号を割り当てます。
- 「提供済み」になった番号は次の注文から再利用されます。
- 提供済み以外の注文で全番号が埋まっている場合、会計を確定せず警告します。
- 番号札の枚数を変える場合は index.html の TICKET_COUNT = 20 を必要な枚数に変更してください。
- 同じ番号の過去の注文履歴は消さずに残るため、注文一覧では注文時刻と状態も確認してください。


【今回の追加機能】
・注文一覧の「調理中」「提供可能」「提供済み」をチェックボックスで複数選択して絞り込めます。
・初期状態では3つすべてが選択され、すべての注文を表示します。
・番号を再利用しても、状態変更や取消は注文ごとに行われます。
・更新時は index.html だけでなく sw.js などZIP内のファイルをすべてGitHub Pagesへアップロードしてください。
・注文データは localStorage に保存されます。データを消したくない場合はサイトデータを削除しないでください。
